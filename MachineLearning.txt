1. INTRODUCTION TO MACHINE LEARNING


Machine Learning (ML) is a branch of Artificial Intelligence (AI) that enables computer systems to learn patterns from data and use those patterns to make predictions, decisions, or discover useful structure.

In traditional programming, a programmer writes explicit rules that a computer follows. In machine learning, an algorithm uses examples or data to learn a model. The learned model can then be used on new data.

Basic machine-learning workflow:
1. Define the problem.
2. Collect relevant data.
3. Clean and prepare the data.
4. Select useful features.
5. Choose an appropriate algorithm.
6. Train or fit the model.
7. Evaluate the model.
8. Improve the model if necessary.
9. Use the model on new data and monitor its performance.

Important terms:
- Dataset: A collection of observations or examples.
- Sample/observation: One record in a dataset.
- Feature: An input variable used by a model.
- Target/label: The output the model is expected to predict in supervised learning.
- Algorithm: The procedure used to learn patterns from data.
- Model: The result of applying a learning algorithm to data.
- Training: The process of fitting a model to data.
- Inference/prediction: Using a trained model on new data.
- Generalization: How well a model performs on unseen data.

============================================================
2. SUPERVISED MACHINE LEARNING
============================================================

2.1 Definition

Supervised learning is a type of machine learning in which a model learns from labelled examples. Each training example contains input features and a known target output. The model learns a relationship between the inputs and target so it can predict targets for new examples.

Simple idea:
Input features + known answers -> learn a mapping -> predict answers for new inputs.

Example:
A dataset contains house size, number of bedrooms, location features, and the actual sale price. The model learns from the known prices and predicts a price for a house it has not seen before.

2.2 What is labelled data?

Labelled data includes the expected answer for each training example.

Example of a labelled dataset:

House size (square feet) | Bedrooms | Sale price
1000                    | 2        | 250000
1500                    | 3        | 350000
2000                    | 3        | 450000

Here, house size and bedrooms are features. Sale price is the target.

For an email classifier:
- Features may include words, sender information, links, and other email characteristics.
- Label may be "spam" or "not spam."

2.3 Main types of supervised learning

A. Regression
Regression predicts a numerical quantity.

Examples:
- Predicting house prices.
- Forecasting sales.
- Estimating electricity demand.
- Predicting temperature.

Common regression algorithms:
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Support Vector Regression (SVR)
- Gradient Boosting Regressor

Typical regression metrics:
- MAE (Mean Absolute Error): Average absolute difference between predictions and actual values.
- MSE (Mean Squared Error): Average squared prediction error.
- RMSE (Root Mean Squared Error): Square root of MSE, expressed in the target's units.
- R-squared (R^2): Measures performance relative to predicting the target mean; interpretation depends on the dataset and evaluation setup.

B. Classification
Classification predicts a category or class.

Examples:
- Spam versus not spam.
- Disease-positive versus disease-negative.
- Fraudulent versus legitimate transaction.
- Image of a cat versus image of a dog.

Common classification algorithms:
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Support Vector Machine (SVM)
- k-Nearest Neighbors (k-NN)
- Naive Bayes
- Neural Networks

Typical classification metrics:
- Accuracy: Fraction of predictions that are correct.
- Precision: Of the examples predicted positive, the fraction that are truly positive.
- Recall: Of the actual positive examples, the fraction correctly identified.
- F1-score: Harmonic mean of precision and recall.
- Confusion matrix: Table showing true positives, true negatives, false positives, and false negatives for binary classification.

Accuracy alone can be misleading when classes are imbalanced. For example, if 99% of records are legitimate, a model that always predicts "legitimate" can achieve 99% accuracy while failing to detect fraud.

2.4 How supervised learning works

1. Collect labelled data.
2. Define the features and target.
3. Split data into training, validation (when needed), and test sets.
4. Fit the model using the training set.
5. Use validation data or cross-validation to tune choices and hyperparameters.
6. Evaluate the final model on held-out test data.
7. Deploy the model and monitor performance.

The test set should not be used repeatedly to make modelling choices, because that can make the reported test performance overly optimistic.

2.5 Training, validation, and test data

- Training set: Used to fit the model's parameters.
- Validation set: Used to compare models or tune hyperparameters.
- Test set: Used for a final, relatively unbiased evaluation after decisions are complete.

For small datasets, cross-validation can help estimate performance more reliably. The split strategy should respect the problem: for example, time-series data often requires chronological splitting, and related records should not leak across splits.

2.6 Overfitting and underfitting

Overfitting occurs when a model learns details or noise specific to the training data and performs poorly on new data.

Underfitting occurs when a model is too simple or insufficiently trained to capture important patterns, resulting in poor performance on both training data and unseen data.

Ways to reduce overfitting:
- Use more representative training data.
- Apply regularization.
- Reduce unnecessary model complexity.
- Use cross-validation.
- Use early stopping when appropriate.
- Avoid data leakage.
- Use data augmentation where suitable.

Ways to address underfitting:
- Use more informative features.
- Select a model capable of capturing the pattern.
- Reduce excessive regularization.
- Train adequately.
- Review data quality and feature engineering.

2.7 Common supervised learning algorithms

Linear Regression:
Models a numerical target as a linear combination of features. It is simple and interpretable, but may not capture complex nonlinear relationships without feature transformations.

Logistic Regression:
Despite its name, it is commonly used for classification. It estimates class probabilities using a logistic function in binary classification, with extensions for multiple classes.

Decision Tree:
Makes predictions using a sequence of feature-based splits. Trees are relatively interpretable but can overfit without suitable constraints.

Random Forest:
Combines many decision trees trained with randomness in samples and/or features. It often improves robustness compared with a single tree.

Support Vector Machine:
Finds a decision boundary that maximizes a margin between classes, or performs regression in SVR form. Kernels can model some nonlinear boundaries.

k-Nearest Neighbors:
Predicts based on nearby training examples. Its results depend on the distance metric, feature scaling, and the choice of k.

Naive Bayes:
Uses Bayes' theorem with a conditional-independence assumption between features given the class. It can be effective for some text-classification tasks.

Neural Networks:
Learn layered transformations of input features. They can model complex patterns but may require more data, computation, and tuning.

2.8 Advantages of supervised learning

- Can learn to predict a clearly defined target.
- Performance can be measured against known answers.
- Supports both numerical prediction and classification.
- Useful for automation and decision-support systems.

2.9 Limitations of supervised learning

- Requires labelled data, which can be costly to collect.
- Label errors can harm performance.
- May learn bias present in the data.
- Can perform poorly when real-world data differs from training data.
- Can overfit or underfit.
- A high metric does not guarantee a model is safe, fair, or useful in every context.

3. UNSUPERVISED MACHINE LEARNING
============================================================

3.1 Definition

Unsupervised learning is a type of machine learning in which an algorithm works with data that does not have a supplied target label for the task. It attempts to discover structure, patterns, relationships, or useful representations in the data.

Simple idea:
Unlabelled data -> discover patterns or structure.

Example:
A retailer has customer purchase histories but no predefined customer groups. Clustering can discover groups with similar purchasing behaviour. A person then examines the groups and decides how to interpret them.

Unsupervised learning does not automatically know the "correct" meaning of a discovered group. Results must be evaluated and interpreted.

3.2 What is unlabelled data?

Unlabelled data contains input features but no supplied answer for each example.

Example:

Customer | Annual income | Spending score
A        | 25000         | 80
B        | 27000         | 75
C        | 90000         | 20
D        | 85000         | 25

There is no provided target such as "high spender" or "low spender." An algorithm may discover groups based on the selected features.

3.3 Main approaches in unsupervised learning

A. Clustering
Groups observations according to a similarity or distance criterion.

Common algorithms:
- K-Means
- Hierarchical/Agglomerative Clustering
- DBSCAN
- Gaussian Mixture Models (GMM)
- Spectral Clustering

Applications:
- Customer segmentation.
- Grouping similar documents.
- Exploring patterns in biological data.
- Grouping similar images or behaviours.

Important concepts:
- Cluster: A group identified by the algorithm.
- Centroid: Mean position of a cluster in algorithms such as K-Means.
- Distance/similarity: A measure used to compare observations.
- Cluster quality: How cohesive and distinct the groups are.

K-Means requires the number of clusters K to be selected. The elbow method and silhouette score can help assess candidate values, but neither guarantees the objectively correct number of clusters.

B. Dimensionality Reduction
Reduces the number of features or creates a lower-dimensional representation while retaining useful information.

Common methods:
- PCA (Principal Component Analysis)
- t-SNE
- UMAP
- Autoencoders

Applications:
- Visualizing high-dimensional data.
- Compressing feature representations.
- Removing redundancy.
- Supporting downstream modelling.

PCA constructs components that capture directions of high variance. t-SNE and UMAP are often used for visualization; distances in a low-dimensional visualization should be interpreted carefully.

C. Anomaly Detection
Identifies observations that differ from the majority or from a model of expected behaviour. It is often used in unsupervised or semi-supervised settings, depending on how the method is trained.

Common methods:
- Isolation Forest
- Local Outlier Factor (LOF)
- One-Class SVM
- Statistical outlier methods

Applications:
- Finding unusual network traffic.
- Flagging unusual transactions.
- Monitoring equipment.
- Detecting data-quality issues.

An anomaly is not necessarily a mistake, fraud, or attack; it is a point requiring investigation.

D. Association Rule Learning
Finds items or events that frequently occur together in transactional data.

Common algorithms:
- Apriori
- FP-Growth
- Eclat

Example rule:
Bread -> Butter

This means that bread purchases are associated with butter purchases in the observed data; it does not establish causation.

Important measures:
- Support: How often an itemset occurs in all transactions.
- Confidence: How often the consequent occurs among transactions containing the antecedent.
- Lift: How much more often the antecedent and consequent co-occur than expected under independence.

E. Representation Learning
Learns useful features or compact representations from data. Autoencoders are a common example: an encoder compresses data into a latent representation and a decoder attempts to reconstruct it.

Some representation-learning methods are unsupervised; others use self-supervised or supervised objectives.

F. Generative Modelling
Learns a data distribution or structure to generate new examples. Variational autoencoders and generative adversarial networks are examples. Modern generative models may use self-supervised or other training objectives, so generative modelling is not always strictly unsupervised.

3.4 How unsupervised learning works

1. Collect data without target labels for the task.
2. Clean the data and handle missing values.
3. Select meaningful features and appropriate representations.
4. Scale features when the algorithm or distance metric requires it.
5. Select an algorithm and its parameters.
6. Fit the model to discover structure.
7. Evaluate the output using suitable metrics, stability checks, visualizations, or domain knowledge.
8. Interpret and validate the discovered patterns.

3.5 Evaluating unsupervised learning

Because ground-truth labels may not be available, evaluation can be more difficult than in supervised learning.

For clustering:
- Silhouette score: Compares how close a point is to its own cluster with how close it is to other clusters.
- Davies-Bouldin index: Lower values generally indicate more distinct, compact clusters.
- Calinski-Harabasz index: Compares between-cluster dispersion with within-cluster dispersion.
- Stability: Checks whether similar clusters appear under reasonable changes in sampling or settings.
- Domain usefulness: Checks whether the clusters are interpretable and useful for the actual task.

If true labels are available only for evaluation, external measures such as Adjusted Rand Index or Normalized Mutual Information can be used. The labels must not be fed into a truly unsupervised training procedure if the goal is to assess unsupervised discovery.

3.6 Advantages of unsupervised learning

- Can work without manually labelled targets.
- Helps explore large datasets.
- Can reveal hidden structure or similarities.
- Can support feature learning and data compression.
- Can help identify unusual observations.

3.7 Limitations of unsupervised learning

- Discovered patterns may be difficult to interpret.
- There may be no single correct clustering or representation.
- Results depend on features, preprocessing, distance measures, and algorithm settings.
- Evaluation is often less direct without labels.
- Algorithms can discover misleading patterns in noisy or biased data.
- Some methods can be computationally expensive.

============================================================

Feature                         Supervised Learning
------------------------------------------------------------
Training data                   Labelled examples
Main objective                  Predict a known target
Typical tasks                   Regression and classification
Example                         Predict house prices
Evaluation                      Compare predictions with known targets
Common algorithms               Linear/logistic regression, trees,
                                random forests, SVM, k-NN, neural networks

Feature                         Unsupervised Learning
------------------------------------------------------------
Training data                   No supplied target labels for the task
Main objective                  Discover patterns or structure

                                association discovery

Evaluation                      Structure metrics, stability, interpretation,
                                domain usefulness
Common algorithms               K-Means, hierarchical clustering, DBSCAN,
                                PCA, Apriori, some autoencoders

Simple memory trick:
- Supervised learning: Learn from examples with answers.
- Unsupervised learning: Find patterns when answers are not supplied.



Semi-supervised learning:
Uses a small labelled dataset together with a larger unlabelled dataset. It is useful when labels are expensive to obtain.

Self-supervised learning:
Creates a training signal from the data itself, such as predicting masked words or missing parts of an image. It is important in modern language and vision models. It is related to unsupervised learning, but is often treated as a distinct paradigm because it uses constructed targets.

Reinforcement learning:
An agent learns actions through interaction with an environment, receiving rewards or penalties. Its objective is to learn behaviour that maximizes long-term reward. It differs from standard supervised and unsupervised learning.


Example 1: Email spam detection
- Inputs: Email text, sender details, links, and other features.
- Target: Spam or not spam.
- Learning type: Supervised classification when examples are labelled.

Example 2: House price prediction
- Inputs: Size, location, bedrooms, age, and other features.
- Target: Sale price.
- Learning type: Supervised regression.

Example 3: Customer segmentation
- Inputs: Income, spending, purchase frequency, and similar features.
- Target: No supplied group label.
- Learning type: Unsupervised clustering.

Example 4: Network anomaly discovery
- Inputs: Network connection measurements or activity features.
- Goal: Identify unusual patterns without requiring a label for every observation.
- Learning type: May use unsupervised anomaly detection; supervised approaches are also possible when labelled attack data is available.

Example 5: Reducing features
- Inputs: A dataset with many numerical features.
- Goal: Represent the data using fewer dimensions.
- Learning type: Unsupervised dimensionality reduction when no target labels guide the transformation.



Q1. What is machine learning?
Machine learning is a field of AI in which algorithms learn patterns from data to make predictions, decisions, or discover structure.

Q2. What is supervised learning?
It learns from labelled examples containing input features and known target outputs.

Q3. What is unsupervised learning?
It discovers structure, patterns, or representations from data without supplied target labels for the task.

Q4. What is the difference between regression and classification?
Regression predicts numerical quantities; classification predicts categories.

Q5. What is clustering?
Clustering groups observations based on similarity or a chosen distance criterion.

Q6. Why is feature scaling important?
For distance-based methods, features with large numerical ranges can dominate the distance. Scaling can make their contributions more comparable.

Q7. What is overfitting?
Overfitting occurs when a model learns training-specific details or noise and performs poorly on new data.

Q8. What is the difference between training and testing?
Training fits the model; testing evaluates its performance on data held out from model fitting and selection.

Q9. Is anomaly detection always unsupervised?
No. It can be unsupervised, semi-supervised, or supervised, depending on the method and available labels.

Q10. Is PCA a clustering algorithm?
No. PCA is a dimensionality-reduction technique. It can be used before clustering, but it does not itself assign cluster labels.

Q11. Does unsupervised learning always find meaningful groups?
No. Results depend on the data, representation, algorithm, and parameters. Discovered patterns must be validated.

Q12. Can a problem use both supervised and unsupervised learning?
Yes. For example, clustering can explore customer groups, and a supervised model can later predict a known outcome using appropriate labelled data.
